# 秋招中台（SQLite 绿色版）

> **模板要你自己填，它替你盯着邮箱**——邮箱自动抓校招邮件，考试/截止/Offer 自动进看板。
> 纯 Python 标准库、零第三方依赖，**数据全部留在本机**（只访问你自己的邮箱，不上传任何服务器）。

校招投递一站式本地中台：**邮箱自动抓取 → 规则引擎解析 → 本地 SQLite 存储 → 实时看板 → Obsidian 笔记同步**。

```
邮件管道(每2小时)                       实时看板(127.0.0.1:8790)
mail.py ──► 中台.sqlite ◄──► 中台看板.py ──► 看板.html（任务/记录/复盘/邮件/设置）
   │            │
   │            └── sync.py ──► Obsidian 公司笔记 frontmatter
   └── 失败邮件 ──► 待确认队列.json（看板里一键重试/忽略）
```

## 功能特性

- **邮件自动解析**：IMAP 拉取 → 主题/正文规则抽取（考试类型、起止时间、截止日、相对时限如"3天内"、考试链接评分、注意事项）
- **未识别邮件自动建档**：邮件能识别出公司名（主题【括号】/发件人显示名/私有域名）时自动创建志愿并归档——感谢信、测评、笔试邮件零录入；识别不出才进待确认队列（设置页可关）
- **状态机推进**：只进不退；已通过/终止为吸收态永不复活；测评/AI 面不推状态
- **考试安排子表**：改期邮件原地更新、重复提醒幂等去重、完成/放弃勾选、日历视图
- **多志愿消歧**：同公司多岗位（独立键=公司+岗位）自动消歧，歧义进待确认队列人工指认
- **待确认队列闭环**：未匹配/歧义/营销邮件 → 看板顶部横幅 → 建好记录后一键重试，或点忽略（有二次确认防手滑）
- **立即拉邮件**：看板右上角「拉邮件」按钮随时手动同步，不用等 2 小时也不用命令行
- **看板四页 + 设置页**：近期任务（3天/本周/自定义）、投递记录（增删改/筛选/分页）、阶段复盘（漏斗/趋势/耗时）、邮件动态，全部数据本机
- **外观自定义**：设置页上传自己的 logo（png/jpg/webp/svg ≤2MB）与站点名称，侧边栏/标签页同步更换，一键恢复默认
- **Obsidian 联动**：自动建公司笔记、刷新 frontmatter、填时间线空行
- **每日快照**：漏斗历史按日 upsert，可回看趋势
- **自动备份**：每轮同步后在线一致性快照到备份目录，滚动保留 30 份

## 环境要求

- **Windows：什么都不用装**——压缩包内置离线 Python 运行时（`tools/runtime/`），双击即用
- macOS / Linux：自带或安装 Python 3.9+（`brew install python3`）
- 纯 Python 标准库实现，**零第三方依赖**；如未来需要依赖，启动器经 UV 按测速最快镜像自动安装
- 一个支持 IMAP 的邮箱（163/QQ/腾讯企业邮/阿里云等，见「支持的邮箱」）

## 启动器做了什么（自动环境检测，双击即用）

`启动中台.bat`（Windows）/ `启动中台.sh`（macOS/Linux）按以下顺序自动选择运行环境：

1. **系统已有 Python ≥3.9** → 直接使用（老用户零操作、零改动）
2. 项目内 `.venv`（之前 uv 建过的虚拟环境）→ 使用
3. **包内置离线运行时** `tools/runtime/`（Windows）→ 使用，无需联网无需安装
4. 检测 uv（系统或项目内）→ `uv sync` 自动建虚拟环境，PyPI 源**实时测速**（清华/阿里/腾讯/中科大/官方）取最快
5. 连 uv 都没有 → 在线多镜像测速下载 uv 到项目内 `tools/`（仅本项目使用，不改系统）
6. 以上全不可用 → 给出明确指引

全程只读写本项目目录；不改系统配置、不写全局 PATH。

## 快速开始（3 步，不用命令行）

1. **双击 `启动中台.bat`**（Windows，无需安装任何东西——内置离线运行时兜底；macOS/Linux 用 `bash 启动中台.sh`）
   - 自动检测环境：已有 Python 直接用 → 没有则用内置运行时 → 再不行用 uv 自动搭建
   - 启动后**浏览器自动打开**看板；重复双击不会开第二个（已在运行就直接开网页）
   - 保持窗口开着 = 看板运行中；关窗口/双击 `停止中台.bat` = 停止
2. **首次使用自动跳到「设置」页**：填 IMAP 服务器（如 `imap.163.com`、`imap.qq.com`）、邮箱账号、授权码 → 点「保存并测试连接」
3. 回「投递记录」页新增第一条志愿；点看板右上角「**拉邮件**」立即同步一次（之后每 2 小时自动同步）

> **163 授权码**：邮箱网页版 → 设置 → POP3/SMTP/IMAP → 开启 IMAP/SMTP 服务并生成授权码（不是登录密码）。
> QQ 邮箱用「授权码」，Gmail 用「应用专用密码」，服务器分别填 `imap.qq.com` / `imap.gmail.com`。

首次运行自动创建 `中台.sqlite`；`mail.py --sync` 首轮只抓最近 30 封。

## 配置说明

**邮箱凭据（凭据.json）**：不手工编辑，在看板「设置」页填写/修改，改完立即生效（下次同步生效）。
密码只写本地文件，接口永远不回传明文。

**运行参数（config.json）**：可在「设置」页改，也可直接编辑文件：

| 键 | 说明 | 默认 |
|---|---|---|
| `端口` | 看板端口（重启看板生效） | `8790` |
| `笔记库目录` | Obsidian 库根目录绝对路径；留空=脚本目录上两级 | 自动 |
| `备份目录` | SQLite 备份目录；留空=本目录 `backups/` | 自动 |
| `公司别名` | 邮件称呼→主表公司名，如 `"字节": "字节跳动"` | 内置几条 |
| `关键词` | 参与解析的邮件主题关键词；留空=内置默认 | 内置 |

首次配置可 `cp config.example.json config.json` 再改。

## 自动定时同步

- **看板自启**：登录时运行 `自启看板.sh`（或直接双击 `启动中台.bat`，已运行则只开网页）
- **同步链**：每 2 小时运行 `sync_pipeline.sh`（收邮件 → 刷笔记 → 备份 → 看板看护）

**macOS / Linux（cron）**：

```cron
0 */2 * * * cd /path/to/中台 && ./sync_pipeline.sh
```

**Windows（纯 Windows，无需 WSL）**：用任务计划程序每 2 小时执行一条命令：

```
cmd /c "cd /d D:\你的目录\秋招中台 && python mail.py --sync && python sync.py"
```

（或创建 `run-sync.bat` 内容为上面两行命令，计划任务指向它。`python` 换成实际解释器，如 `py -3`。）

## 常见问题

- **双击 启动中台.bat 闪退**：大概率没装 Python 或没勾 "Add Python to PATH"。命令行运行 `python --version` 能出版本号才行；也可能是直接在压缩包里双击（启动器会提示先解压）。
- **双击后窗口里一堆红字**：看报错最后一行；端口被占用 → 现在会给中文指引（看板其实已在运行就重新双击直接开网页，被别的程序占用就改 config.json 的端口）。
- **测试连接失败**：163 未开 IMAP 服务 / 授权码输错 / 网络代理拦截。关闭代理或换网络再试（看板里已会把常见原因翻成人话）。
- **建错了志愿想删**：投递记录 → 展开该行 → 底部「删除此志愿」（会连同考试安排/邮件存档一起删，有确认框；只是没进展建议改「终止」）。
- **怎么停止看板**：关掉启动时的黑窗口，或双击 `停止中台.bat`。
- **队列里邮件重试总失败**：看「原因」——公司未匹配就先去投递记录页建对应公司（名称要和邮件里称呼一致，或加到「公司别名」）；歧义就把同公司多余志愿补上岗位名。
- **营销邮件一直在队列**：点「忽略」即可，已标记不再提醒。
- **改了端口打不开**：重启看板进程后生效；自启/定时/启动器都会自动读 config.json 里的端口。
- **邮件没被解析**：主题不含任何关键词的邮件会跳过（只标记已见）；可在设置里补充关键词。
- **想清空重来**：关闭看板后删 `中台.sqlite`（先备份！），再跑迁移工具或手动重建志愿。

## 已知边界

- 邮件解析规则针对中文校招邮件定制；主题含英文关键词（assessment/interview/offer 等）的邮件也会进管道，但英文正文里的时间窗解析精度不如中文
- 关键词只匹配主题；正文-only 通知不会触发解析
- 规则引擎（时间窗/链接评分等）的阈值是经验值，见 `mail.py` 内注释，可按需调整
